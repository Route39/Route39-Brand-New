1. SMS / OTP Integration
The OTP functionality is implemented identically on both the Customer and Driver sides using a 2-step verification flow:

Request OTP: Sends the 10-digit mobile number to the backend.
Verify OTP: Sends the number and the 6-digit code entered by the user.

Manages the UI with two stacked views (login and otp).
Implements a modern hybrid login with a 30-second cooldown timer for the "Resend OTP" action.
Logic File: 
CustomerApp.jsx
requestOtp: Triggers POST /api/customer-auth/request-otp with { phone: "..." }. Handles SMS/WhatsApp transport based on response.
verifyOtp: Triggers POST /api/customer-auth/verify-otp with { phone, otp, name }. On success, sets the token in localStorage (r39_customer_token) and transitions to the booking flow.
Driver App Implementation

Login View: 
DriverLogin.jsx
 captures the phone number and calls requestOtp.
Verify View: DriverOtpVerify.jsx captures the OTP and calls verifyOtp.

2. Map & Location Integration
The map feature relies heavily on the Google Maps JavaScript API instead of Mapbox, avoiding dependencies and natively handling everything from picking locations to live-tracking drivers.

API Key Used: The integration relies on the .env variable REACT_APP_GOOGLE_MAPS_API_KEY.

Customer App Implementation (Pickup & Drop)
Primary Map Component: 
GoogleMapPicker.jsx
Map Initialization: Lazy-loads the Google Maps script via loadGoogleMaps().
Geolocation: Uses resolveCurrentLocation() which first attempts to use the native Capacitor plugin (@capacitor/geolocation), and falls back to standard browser navigator.geolocation.
Booking Pins (<GoogleMapPicker>):
Displays a two-pin picker (Pickup and Drop) using data-URI SVGs for sharp rendering.
Draws a dashed polyline (maps.Polyline) between the two points to show the route without consuming extra billing via the Directions API.
Live Trip Tracking (<LiveTripMap>):
Continuously updates the driver's position smoothly via animateMarkerTo() to glide the marker (so 2.5-second polling looks like continuous movement).
Refits the bounds automatically to include Pickup, Drop, and Driver locations.
Driver App Implementation (Live Tracking & Navigation)
Primary Component: 
ActiveTripScreen.jsx
GPS Poller (pingGps function):
Uses navigator.geolocation.getCurrentPosition (every 4 seconds) with enableHighAccuracy: true to get lat, lng, speed, heading, and accuracy.

Interactive Map:

        if (bookForm.trip_type === "scheduled" && !bookForm.scheduled_at) {
            toast.error("Pick a date & time for scheduled bookings"); return;

    };
    // iter-74: New CustomerBookFlow takes a fully-built body and posts it.
    // Wraps the legacy `submitBooking` plumbing so both can co-exist while

    const submitBookingBody = async (body) => {
        const { data } = await authedAxios().post("/customer/bookings", body);

        // Refresh list so top-level live-trip detection sees the new booking.
        try {
            const { data: list } = await authedAxios().get("/customer/bookings");

    const needsPaymentBooking = useMemo(

    const liveOrPay = liveBooking || needsPaymentBooking;

    useEffect(() => {

                    }}

                    onNavChange={isPaymentPending ? () => {} : (nav) => {

                    }}

                <CustomerMenuDrawer

    }

    // ============================================================

    // ============================================================
    if (!me && (view === "login" || view === "otp")) {

/**
 * CustomerLiveTripScreen â€” full-viewport Modern Hybrid live tracker.
 * Wraps <CustomerLiveTrip /> and feeds it driver location + ETA, and mounts
 * PaymentSheet / RatingBlock as children when the booking reaches COMPLETED.
 */
function CustomerLiveTripScreen({ booking: initial, onBack, onCancel, onCallDriver, onSessionPaid, onNavChange, me }) {
    const [b, setB] = useState(initial);
    const [driverLoc, setDriverLoc] = useState(null);
    const [etaMin, setEtaMin] = useState(null);

    // Sync incoming booking refresh from parent
    useEffect(() => { setB(initial); }, [initial]);

    // Poll booking + driver location every 6s while live
    useEffect(() => {
        if (!b?.booking_id) return;
        let alive = true;
        const tick = async () => {
            try {
                const { data } = await authedAxios().get(`/customer/bookings/${b.booking_id}`);
                if (alive && data) setB((prev) => ({ ...prev, ...data }));
            } catch { /* silent */ }
            if (["ACCEPTED", "ARRIVED", "STARTED"].includes(b.status)) {
                try {
                    const { data } = await authedAxios().get(`/customer/bookings/${b.booking_id}/driver-location`);
                    if (!alive) return;
                    setDriverLoc(data?.location);
                    setEtaMin(data?.eta_min ?? null);
                } catch { /* silent */ }
            }
        };
        tick();
        const t = setInterval(tick, 2500);
        return () => { alive = false; clearInterval(t); };
    }, [b?.booking_id, b?.status]);

    const isPaid = b?.payment_status === "PAID";
    const showSOS = ["ACCEPTED", "ARRIVED", "STARTED"].includes(b?.status) || (b?.status === "COMPLETED" && !isPaid);

    return (
        <>
            <CustomerLiveTrip
                booking={b}
                showSOS={showSOS}
                driverLocation={driverLoc}
                etaMin={etaMin}
                onBack={onBack}
                onCancel={onCancel}
                onCallDriver={onCallDriver}
                onNavChange={onNavChange}
                me={me}
            >
                {/* COMPLETED â†’ payment OR rating */}
                {b.status === "COMPLETED" && (b.payment_status || "PENDING") !== "PAID" && (
                    <PaymentSheet booking={b} onPaid={(newStatus) => {
                        // iter-fix: cash flow â†’ CASH_PENDING state; driver confirm à®ªà®£à¯à®£à®¾ à®®à®Ÿà¯à®Ÿà¯à®®à¯ PAID
                        if (newStatus === "CASH_PENDING") {
                            if (onSessionPaid) onSessionPaid(b.booking_id);
                            setB(p => ({ ...p, payment_status: "CASH_PENDING" }));
                            // polling already running every 6s â€” will detect PAID when driver confirms
                        } else {
                            if (onSessionPaid) onSessionPaid(b.booking_id);
                            setB(p => ({ ...p, payment_status: "PAID" }));
                        }
                    }} />
                )}
                {b.status === "COMPLETED" && b.payment_status === "PAID" && (
                    <RatingBlock booking={b} onRated={onBack} onClose={onBack}/>
                )}
            </CustomerLiveTrip>
        </>
    );
}

let _rzpScriptPromise = null;
function loadRazorpayScript() {
    if (window.Razorpay) return Promise.resolve(true);
    if (_rzpScriptPromise) return _rzpScriptPromise;
    _rzpScriptPromise = new Promise((resolve) => {
        const s = document.createElement("script");
        s.src = "https://checkout.razorpay.com/v1/checkout.js";
        s.onload = () => resolve(true);
        s.onerror = () => resolve(false);
        document.head.appendChild(s);
    });
    return _rzpScriptPromise;
}

function AddressRow({ kind, active, value, placeholder, onActivate, onClear, searchQ, onSearchChange, results, onPick, extra }) {

    // When the row becomes active and is empty, autofocus its input.

        if (active && !value && inputRef.current) {
            const t = setTimeout(() => inputRef.current?.focus(), 50);
            return () => clearTimeout(t);
        }
    }, [active, value]);

    return (
        <div
            className={`relative rounded-xl transition-colors ${
                active
                    ? (isPickup ? "bg-emerald-500/10 ring-1 ring-emerald-400/30" : "bg-rose-500/10 ring-1 ring-rose-400/30")

function BookView({ form, setForm, busy, onSubmit, bookings, onCancel, me }) {
    const [activePin, setActivePin] = useState("pickup"); // pickup | drop
    const [searchQ, setSearchQ] = useState("");
    const [searchResults, setSearchResults] = useState([]);
    const [estimate, setEstimate] = useState(null);
    const [estimating, setEstimating] = useState(false);
    const [gpsLoading, setGpsLoading] = useState(false);
    const [gpsHint, setGpsHint] = useState(""); // "" | "denied" | "unavailable"
    const autoDetectAttemptedRef = useRef(false);

    // iter-73: live-trip is now handled at the top of CustomerApp (full-viewport
    // CustomerLiveTrip). BookView only renders the booking form.

    // Search debounce
    useEffect(() => {
        if (!searchQ.trim()) { setSearchResults([]); return; }
        const t = setTimeout(async () => {
            const res = await geocodeSearch(searchQ);
            setSearchResults(res);
        }, 300);
        return () => clearTimeout(t);
    }, [searchQ]);

    // Pin clicked on map
    const onPinChange = (pin) => {
        if (activePin === "pickup") {
            setForm(f => ({ ...f, pickup: pin.address, pickup_lat: pin.lat, pickup_lng: pin.lng }));
            // Auto-advance to drop when pickup just got set and drop is empty
            if (!form.drop_lat) setActivePin("drop");
        } else {
            setForm(f => ({ ...f, drop: pin.address, drop_lat: pin.lat, drop_lng: pin.lng }));
        }
    };

    const pickSearchResult = async (r) => {
        // Google Places returns predictions WITHOUT coordinates (Mapbox shipped them inline).
        // Fetch geometry via Place Details on selection â€” this consumes the session token
        // so Google bills autocomplete + details as a single call.
        let lat, lng, address;
        if (r.center) {
            // Back-compat: Mapbox-shape result (still possible if loader fails over)
            [lng, lat] = r.center;
            address = r.place_name;
        } else if (r.place_id) {
            try {
                const d = await getPlaceCoords(r.place_id);
                lat = d.lat; lng = d.lng;
                address = d.address || r.place_name;
            } catch (e) {
                toast.error("Couldn't fetch that place. Try again or tap the map.");
                return;
            }
        } else {
            return;
        }
        if (lat == null || lng == null) return;
        onPinChange({ lat, lng, address });
        setSearchQ(""); setSearchResults([]);
    };

    // Resolve user GPS â†’ reverse-geocode â†’ set pickup. Idempotent â€” caller
    // controls when this fires (auto on mount + on "Use current location" tap).
    const detectAndSetPickup = async (opts = {}) => {
        const { silent = false } = opts;
        if (gpsLoading) return;
        setGpsLoading(true);
        setGpsHint("");
        try {
            const { lat, lng } = await resolveCurrentLocation({ timeoutMs: 8000 });
            const address = await reverseGeocode(lng, lat);
            setForm(f => ({ ...f, pickup: address, pickup_lat: lat, pickup_lng: lng }));
            // Auto-advance focus to drop unless drop already filled
            setActivePin(prev => (prev === "pickup" && !form.drop_lat ? "drop" : prev));
            if (!silent) toast.success("Pickup set to your current location");
        } catch (e) {
            const code = e?.code || "unavailable";
            setGpsHint(code === "permission_denied" ? "denied" : "unavailable");
            if (!silent) {
                toast.error(
                    code === "permission_denied"
                        ? "Location access denied. Tap the map or search instead."
                        : "Couldn't fetch location. Tap the map or search instead.",
                );
            }
        } finally {
            setGpsLoading(false);
        }
    };

    // Auto-detect on mount â€” single attempt, only if pickup is empty.
    useEffect(() => {
        if (autoDetectAttemptedRef.current) return;
        if (form.pickup_lat) return; // user already has a pickup (e.g. came back from a previous booking)
        autoDetectAttemptedRef.current = true;
        // Run silently â€” failures shouldn't surprise the user before they've engaged with the form.
        detectAndSetPickup({ silent: true });
        // eslint-disable-next-line react-hooks/exhaustive-deps
    }, []);

    // Fetch fare estimate when both pins + trip type are ready
    useEffect(() => {
        if (!form.pickup_lat || !form.drop_lat) { setEstimate(null); return; }
        let alive = true;
        setEstimating(true);
        (async () => {
            try {
                const { data } = await authedAxios().post("/customer/fare-estimate", {
                    pickup_location: { lat: form.pickup_lat, lng: form.pickup_lng },
                    drop_location: { lat: form.drop_lat, lng: form.drop_lng },
                    trip_type: form.trip_type,
                    rental_hours: form.rental_hours ? Number(form.rental_hours) : undefined,
                });
                if (alive) setEstimate(data);
            } catch { /* silent */ }
            if (alive) setEstimating(false);
        })();
        return () => { alive = false; };
    }, [form.pickup_lat, form.drop_lat, form.trip_type, form.rental_hours]);

    return (
        <main className="flex-1 flex flex-col" data-testid="cust-book-view">
            {/* iter-73: live trip is now full-viewport at the App level. BookView only renders the form. */}
            <>
                <div className="relative">
                    <div className="px-3 pt-1">
                        <MapboxPicker
                            pickup={form.pickup_lat ? { lat: form.pickup_lat, lng: form.pickup_lng, address: form.pickup } : null}
                            drop={form.drop_lat ? { lat: form.drop_lat, lng: form.drop_lng, address: form.drop } : null}
                            activePin={activePin}
                            onPinChange={onPinChange}
                            height={300}
                        />
                    </div>
                </div>

            {/* Bottom sheet */}
            <div className="flex-1 mt-3 px-5 pb-8 -mt-2 relative bg-gradient-to-b from-transparent via-[#0a0a0f]/60 to-[#0a0a0f] backdrop-blur-xl rounded-t-3xl border-t border-white/10">
                <div className="w-10 h-1 bg-white/20 rounded-full mx-auto -mt-3 mb-4" />

                <form onSubmit={onSubmit} className="space-y-3">
                    {/* Address rows â€” click to inline-edit, with embedded search/autocomplete */}
                    <div className="bg-white/5 border border-white/10 rounded-2xl p-2.5 space-y-1.5">
                        {/* PICKUP row */}
                        <AddressRow
                            kind="pickup"
                            active={activePin === "pickup"}

/**
 * Probe current device location once. Tries Capacitor native plugin first
 * (inside the wrapped APK/IPA), falls back to browser Geolocation API.
 */
export async function resolveCurrentLocation({ timeoutMs = 10000 } = {}) {
    try {
        if (typeof window !== "undefined" && window.Capacitor?.isNativePlatform?.()) {
            const { Geolocation } = await import("@capacitor/geolocation").catch(() => ({ Geolocation: null }));
            if (Geolocation) {
                const perm = await Geolocation.checkPermissions();
                if (perm.location !== "granted") {
                    const req = await Geolocation.requestPermissions();
                    if (req.location !== "granted") {
                        const err = new Error("Location permission denied");
                        err.code = "permission_denied";
                        throw err;
                    }
                }
                const pos = await Geolocation.getCurrentPosition({ enableHighAccuracy: true, timeout: timeoutMs, maximumAge: 0 });
                return { lat: pos.coords.latitude, lng: pos.coords.longitude, accuracy_m: pos.coords.accuracy };
            }
        }
    } catch (e) {
        if (e?.code === "permission_denied") throw e;
    }
    if (typeof navigator === "undefined" || !navigator.geolocation) {
        const err = new Error("Geolocation not supported on this device");
        err.code = "unsupported";
        throw err;
    }
    return new Promise((resolve, reject) => {
        navigator.geolocation.getCurrentPosition(
            (p) => resolve({ lat: p.coords.latitude, lng: p.coords.longitude, accuracy_m: p.coords.accuracy }),
            (err) => {
                const e = new Error(err.message || "Geolocation failed");
                if (err.code === 1) e.code = "permission_denied";
                else if (err.code === 3) e.code = "timeout";
                else e.code = "unavailable";
                reject(e);
            },
            { enableHighAccuracy: true, timeout: timeoutMs, maximumAge: 0 },
        );
    });
}

export function useUserLocation() {
    const [coords, setCoords] = useState(null);
    useEffect(() => {
        let alive = true;
        resolveCurrentLocation()
            .then(({ lat, lng }) => { if (alive) setCoords([lng, lat]); })
            .catch(() => { if (alive) setCoords(DEFAULT_CENTER); });
        return () => { alive = false; };
    }, []);
    return coords || DEFAULT_CENTER;
}

/**
 * Two-pin map (pickup + drop). Click anywhere to set the active pin.
 * onPinChange({ lat, lng, address }).
 *
 * Init flow (Uber-style):
 *   1. Probe GPS first (up to 10s hard cap)
 *   2. Once we have ANY center (real GPS or fallback), load Google Maps
 *   3. Render the Map at that center directly â€” no jump, no flicker
 *   4. Drop a blue "you are here" marker (only when we have real GPS)
 *   5. "Recenter to me" floating button always available
 */
export default function GoogleMapPicker({ pickup, drop, activePin, onPinChange, height = 320, fullScreen = false }) {
    const containerRef = useRef(null);
    const mapRef = useRef(null);
    const pickupMarkerRef = useRef(null);
    const dropMarkerRef = useRef(null);
    const polylineRef = useRef(null);
    const meMarkerRef = useRef(null);
    const meAccuracyRef = useRef(null);

    // Phase 1 â€” GPS probe. `meCoords` holds REAL location only (null if not granted).
    // `initialCenter` is whatever we'll seed the map with (GPS preferred, fallback after timeout).
    const [meCoords, setMeCoords] = useState(null);
    const [initialCenter, setInitialCenter] = useState(null);
    const [locating, setLocating] = useState(true);
    const [ready, setReady] = useState(false);
    const [err, setErr] = useState("");

    useEffect(() => {
        let alive = true;
        // Hard cap so we never block the booking flow indefinitely.
        const fallbackTimer = setTimeout(() => {
            if (!alive) return;
            setInitialCenter((prev) => prev || { lat: DEFAULT_CENTER[1], lng: DEFAULT_CENTER[0] });
            setLocating(false);
        }, 10000);

        resolveCurrentLocation({ timeoutMs: 10000 })
            .then(({ lat, lng, accuracy_m }) => {
                if (!alive) return;
                setMeCoords({ lat, lng, accuracy_m: accuracy_m || 30 });
                setInitialCenter({ lat, lng });
                setLocating(false);
                clearTimeout(fallbackTimer);
            })
            .catch((e) => {
                if (!alive) return;
                if (e?.code === "permission_denied") {
                    setErr("Please enable location to book a ride");
                } else {
                    setInitialCenter({ lat: DEFAULT_CENTER[1], lng: DEFAULT_CENTER[0] });
                }
                setLocating(false);
                clearTimeout(fallbackTimer);
            });
        return () => { alive = false; clearTimeout(fallbackTimer); };
    }, []);

    // Phase 2 â€” once we have a center, init Google Maps. Map is created ONCE.
    useEffect(() => {
        if (!initialCenter || mapRef.current) return;
        let alive = true;
        loadGoogleMaps()
            .then((maps) => {
                if (!alive || !containerRef.current || mapRef.current) return;
                const map = new maps.Map(containerRef.current, {
                    center: initialCenter,
                    zoom: meCoords ? 15 : 12,
                    disableDefaultUI: true,
                    zoomControl: true,
                    clickableIcons: false,
                    gestureHandling: "greedy",
                    styles: _mapsStyleForTheme(),
                });
                mapRef.current = map;
                map.addListener("click", async (e) => {
                    const coords = { lat: e.latLng.lat(), lng: e.latLng.lng() };
                    const address = await reverseGeocode(coords.lng, coords.lat);
                    onPinChange({ ...coords, address });
                });
                setReady(true);
            })
            .catch((e) => alive && setErr(e?.message || "Failed to load map"));
        return () => { alive = false; };
        // eslint-disable-next-line react-hooks/exhaustive-deps
    }, [initialCenter]);

    // Phase 3 â€” paint / update the "you are here" marker whenever real GPS lands.
    useEffect(() => {
        if (!ready || !mapRef.current || !window.google?.maps || !meCoords) return;
        const maps = window.google.maps;
        const pos = { lat: meCoords.lat, lng: meCoords.lng };
        if (meMarkerRef.current) {
            meMarkerRef.current.setPosition(pos);
            if (meAccuracyRef.current) meAccuracyRef.current.setCenter(pos);
        } else {
            meMarkerRef.current = new maps.Marker({
                position: pos,
                map: mapRef.current,
                icon: { url: ME_ICON, anchor: new maps.Point(11, 11) },
                title: "You are here",
                zIndex: 9999,
            });
            meAccuracyRef.current = new maps.Circle({
                map: mapRef.current,
                center: pos,
                radius: Math.min(120, Math.max(15, meCoords.accuracy_m || 30)),
                strokeColor: "#3b82f6",
                strokeOpacity: 0.4,
                strokeWeight: 1,
                fillColor: "#3b82f6",
                fillOpacity: 0.12,
                clickable: false,
            });
        }
    }, [ready, meCoords?.lat, meCoords?.lng, meCoords?.accuracy_m]);

    // Add random standing autos nearby
    useEffect(() => {
        if (!ready || !mapRef.current || !window.google?.maps || !meCoords) return;
        const maps = window.google.maps;
        const autos = [];
        for (let i = 0; i < 4; i++) {
            const rLat = meCoords.lat + (Math.random() - 0.5) * 0.015;
            const rLng = meCoords.lng + (Math.random() - 0.5) * 0.015;
            autos.push(new maps.Marker({

/**
 * Lightweight map showing driver's live location during the trip. Auto-pans
 * to the driver's position on every update.
 */
// Smoothly glides a marker from its current position to a new one instead of
// snapping â€” makes 2.5s location-poll updates read as continuous movement.
function animateMarkerTo(marker, to, maps, duration = 1000) {
    const from = marker.getPosition();
    if (!from) { marker.setPosition(to); return; }
    const fromLat = from.lat(), fromLng = from.lng();
    const dLat = to.lat - fromLat, dLng = to.lng - fromLng;
    // Skip animating negligible or teleport-scale jumps (e.g. first fix after a gap)
    if (Math.abs(dLat) < 1e-9 && Math.abs(dLng) < 1e-9) return;

    const start = performance.now();
    const ease = (t) => 1 - Math.pow(1 - t, 3); // ease-out cubic

    const step = (now) => {
        const t = Math.min(1, (now - start) / duration);
        const e = ease(t);
        marker.setPosition({ lat: fromLat + dLat * e, lng: fromLng + dLng * e });
        if (t < 1) requestAnimationFrame(step);
    };
    requestAnimationFrame(step);
}

    const mapRef = useRef(null);
    const driverMarkerRef = useRef(null);
    const polylineRef = useRef(null); // Used for driver-pickup connection line
    const routePolylineRef = useRef(null); // Used for pickup-drop route line
    const fittedRef = useRef(false);
    const [ready, setReady] = useState(false);

    useEffect(() => {

                    });

                        position: { lat: drop.lat, lng: drop.lng },
                        map, icon: { url: DROP_ICON, anchor: new maps.Point(16, 16) }, title: "Drop",
                    });
                }
                // Pickupâ†’drop polyline so the rider sees the planned route at a glance.
                if (pickup?.lat && drop?.lat) {
                    routePolylineRef.current = new maps.Polyline({
                        path: [
                            { lat: pickup.lat, lng: pickup.lng },
                            { lat: drop.lat, lng: drop.lng },
                        ],
                        geodesic: true,
                        strokeOpacity: 0,
                        icons: [{
                            icon: { path: "M 0,-1 0,1", strokeOpacity: 1, scale: 2.5, strokeColor: "#FF4D4F", strokeWeight: 3 },
                            offset: "0",
                            repeat: "12px"
                        }],
                        map,
                    });
                }
                
                setReady(true);
            })
            .catch(() => { /* silent â€” map will simply not render */ });
        return () => { alive = false; };
        // eslint-disable-next-line react-hooks/exhaustive-deps
    }, []);

    // Fit-to-bounds once we have all relevant points (pickup + drop + driver, when present).
    // Only fires ONCE per mount so the user can still pan/zoom without snap-back on every
    // driver location tick.

        if (!ready || !mapRef.current || !window.google?.maps || fittedRef.current) return;
        
        // Priority: Driver Location > Pickup Location > Drop Location
        const pt = driverLocation?.lat ? { lat: driverLocation.lat, lng: driverLocation.lng }
                 : pickup?.lat ? { lat: pickup.lat, lng: pickup.lng }
                 : drop?.lat ? { lat: drop.lat, lng: drop.lng }
                 : null;

        if (pt) {
            mapRef.current.panTo(pt);
            mapRef.current.setZoom(16);
            fittedRef.current = true;
        }
    }, [ready, pickup?.lat, drop?.lat, driverLocation?.lat]);

    useEffect(() => {
        if (!ready || !mapRef.current || !window.google?.maps || !driverLocation) return;
        const { lat, lng } = driverLocation;
        if (!lat || !lng) return;
        
        const maps = window.google.maps;

        if (driverMarkerRef.current) {
            animateMarkerTo(driverMarkerRef.current, { lat, lng }, maps);
        } else {
            driverMarkerRef.current = new maps.Marker({
                position: { lat, lng },
                map: mapRef.current,
                icon: { url: DRIVER_ICON, anchor: new maps.Point(22, 22) },
                title: "Driver",
            });
        }

        // Dynamic connecting line from Customer (pickup) to Driver
        if (pickup?.lat && pickup?.lng) {
            const path = [
                { lat: pickup.lat, lng: pickup.lng },
                { lat, lng }
            ];
            
            if (polylineRef.current) {
                polylineRef.current.setPath(path);
            } else {
                polylineRef.current = new maps.Polyline({
                    path,
                    geodesic: true,
                    strokeColor: "#f59e0b", // Theme color amber
                    strokeOpacity: 0,
                    strokeWeight: 3,
                    icons: [{
                        icon: { path: 'M 0,-1 0,1', strokeOpacity: 1, scale: 2.5 },
                        offset: '0',
                        repeat: '10px'
                    }],
                    map: mapRef.current,
                });
            }
        }

        // Only pan after the initial fit â€” gentle follow, no zoom changes.
        if (fittedRef.current) mapRef.current.panTo({ lat, lng });
    }, [ready, driverLocation?.lat, driverLocation?.lng, pickup?.lat, pickup?.lng]);

    return (
        <div
            className={fullScreen ? "w-full h-full bg-slate-900" : "rounded-xl overflow-hidden bg-slate-900"}
            style={fullScreen ? undefined : { height }}
            data-testid="cust-live-trip-map"
        >
            <div ref={containerRef} className="w-full h-full" />
        </div>
    );
}

// â”€â”€â”€ Lazy-load Google Maps JS API (only once) â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€â”€
let _mapsPromise = null;
function loadGoogleMaps() {
    if (!GMAPS_KEY) return Promise.reject(new Error("No API key"));
    if (window.google?.maps) return Promise.resolve(window.google.maps);
    if (_mapsPromise) return _mapsPromise;
    _mapsPromise = new Promise((resolve, reject) => {
        const cb = `__r39MapsInit_${Date.now()}`;
        window[cb] = () => { resolve(window.google.maps); delete window[cb]; };
        const s = document.createElement("script");
        s.src = `https://maps.googleapis.com/maps/api/js?key=${GMAPS_KEY}&libraries=geometry&callback=${cb}`;
        s.async = true;
        s.onerror = (e) => { reject(e); _mapsPromise = null; delete window[cb]; };
        document.head.appendChild(s);
    });
    return _mapsPromise;
}

// â”€â”€â”€ Direct call helper (no masking â€” dials the customer's real number) â”€â”€â”€â”€â”€
function maskPhone(phone) {
    if (!phone) return "";
    const digits = String(phone).replace(/\D/g, "");
    if (digits.length <= 3) return digits;
    return "â€¢".repeat(digits.length - 3) + digits.slice(-3);
}

            // Throttle: recalc the real road route only every ~12s or after
            // moving ~40m, so we don't spam the Directions API on every
            // 4-second GPS tick â€” the blue line still visibly redraws as
            // the driver progresses, matching Google Maps behaviour.
            const last = lastRouteFetchRef.current;

                const dLng = (driverPos.lng - last.lng) * Math.PI / 180;
                const a = Math.sin(dLat / 2) ** 2 + Math.cos(last.lat * Math.PI / 180) * Math.cos(driverPos.lat * Math.PI / 180) * Math.sin(dLng / 2) ** 2;
                movedFar = R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a)) > 40;
            }
            if (movedFar || now - last.ts > 12000) {
                lastRouteFetchRef.current = { lat: driverPos.lat, lng: driverPos.lng, ts: now };
                directionsServiceRef.current.route(
                    {
                        origin: pos,
                        destination: { lat: navTarget.lat, lng: navTarget.lng },
                        travelMode: window.google.maps.TravelMode.DRIVING,
                    },
                    (result, status) => {
                        if (status === "OK" && directionsRendererRef.current) {
                            directionsRendererRef.current.setDirections(result);
                        }
                    }
                );
            }
        }
    }, [driverPos, booking.status, booking.drop_location, booking.pickup_location]);

    if (mapError || !GMAPS_KEY) return <DecorativeMap />;

    return (
        <div className="absolute inset-0">
            <div ref={containerRef} className="w-full h-full" />
             {!mapReady && <DecorativeMap />}
        </div>
    );
}
